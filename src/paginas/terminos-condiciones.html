En cumplimiento de la Resolución 424/2020, el usuario dispone de 10 días corridos para revocar la contratación desde la aceptación, siempre que el software no haya sido utilizado para producir valor comercial en ese lapso.

4. Propiedad de los Datos y Portabilidad

Los datos cargados en el sistema son 100% propiedad del CLIENTE. ADEMA Sistemas actúa únicamente como procesador de dicha información. Se garantiza el derecho a la "Portabilidad de Datos" (exportación en formatos estándar como CSV o Excel) al finalizar el contrato, siempre que no exista deuda pendiente por parte del CLIENTE.

5. Uso de Datos de Google (Google Drive)

Cuando el CLIENTE habilita la integración con Google Drive para respaldos automáticos, ADEstock solicita acceso restringido únicamente para crear, actualizar y gestionar archivos de respaldo generados por el sistema. ADEstock no lee, modifica ni elimina otros archivos del usuario que no hayan sido creados como respaldo por la aplicación.

El uso de la información recibida a través de las APIs de Google cumple con la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado (Limited Use).
