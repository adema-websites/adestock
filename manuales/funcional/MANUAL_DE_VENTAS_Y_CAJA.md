# Manual de Ventas y Caja

Este es el módulo más utilizado. Aquí aprenderá a operar el Punto de Venta (POS) de manera ágil y segura.

---

## 1. Apertura de Caja

Antes de vender, debe abrir la caja.

1.  Ingrese al módulo **Venta**.
2.  El sistema verificará si tiene una caja abierta. Si no, le pedirá abrirla.
3.  **Monto Inicial:** Ingrese el dinero con el que arranca (cambio/sencillo). Ej: $5.000.

---

## 2. Realizar una Venta

La pantalla de ventas está diseñada para ser rápida.

1.  **Buscar Producto:**
    *   Use el lector de código de barras.
    *   O escriba el nombre (ej. "Coca") en el buscador.
    *   O haga clic en los botones de acceso rápido (si están configurados).
2.  **Cantidad:** Por defecto es 1. Puede cambiarla con `+` y `-` o escribiendo el número.
3.  **Cliente (Opcional):** Por defecto es "Consumidor Final". Si el cliente pide factura A o quiere fiado, búsquelo en la lupa de clientes.
4.  **Cobrar:**
    *   Haga clic en el botón **Cobrar** (o presione F9/Enter según configuración).
    *   Seleccione el **Medio de Pago** (Efectivo, Débito, MercadoPago).
    *   Si es Efectivo, ingrese con cuánto paga el cliente para que el sistema le diga el vuelto.
5.  **Confirmar:** Al finalizar, se imprime el ticket automáticamente (ver Manual de Impresoras).

---

## 3. Operaciones Especiales

*   **Descuentos:** Puede aplicar un % de descuento a un producto específico o al total de la venta (requiere permisos).
*   **Eliminar Item:** Si se equivocó, haga clic en el ícono de basura al lado del producto antes de cobrar.
*   **Cancelar Venta:** Si el cliente se arrepiente antes de pagar, use el botón "Cancelar Venta" para limpiar la pantalla.

---

## 4. Cierre de Caja (Arqueo)

Al finalizar el turno:

1.  Haga clic en **Cerrar Caja**.
2.  El sistema le mostrará el **Resumen Teórico**:
    *   Ventas en Efectivo: $100.000
    *   Ventas en Tarjeta: $50.000
    *   Gastos/Retiros: -$10.000
    *   **Total Esperado en Cajón:** $90.000
3.  **Conteo Real:** Cuente el dinero físico y compárelo.
4.  Confirme el cierre. Se generará un reporte PDF con el detalle para rendir cuentas.
