¿Qué es Agent Printer?

Es un pequeño programa para Windows que corre en la PC de tu local o sucursal. Se conecta a ADEstock Cloud, toma los trabajos de impresión encolados y los envía a la impresora física que tengas instalada — ya sea por USB o por red local (LAN).

Sin abrir puertos. El agente solo hace conexiones salientes hacia ADEstock Cloud. Tu red local nunca queda expuesta a Internet, cumpliendo con los estándares de seguridad más exigentes.

El Problema que Resuelve

Sin Agent Printer

Un sistema cloud no puede acceder directamente a una impresora USB ni a una red privada de sucursal. Imprimir desde Internet a hardware local es técnicamente imposible sin un puente.

Con Agent Printer

El agente actúa de puente seguro: consulta nuevos trabajos de impresión cada pocos segundos, los ejecuta en la impresora local y reporta el resultado al sistema cloud.

Multi-caja y Multi-sucursal

Cada agente se vincula a una caja y sucursal específica. Podés tener tantos agentes como cajas activas, todos administrados desde ADEstock Cloud sin configuraciones adicionales.

Características Principales

USB y LAN

Soporta impresoras conectadas por cable USB (por nombre de impresora Windows) y por red local IP/puerto (habitual 9100).

Tickets ESC/POS

Compatible con cualquier impresora térmica que entienda ESC/POS — el estándar de la industria para tickets de venta y comprobantes.

Monitoreo en Tiempo Real

El agente envía un heartbeat periódico al sistema cloud. Si deja de responder, ADEstock te alerta para que puedas actuar antes de que afecte la operación.

Reintentos Automáticos

Si una impresión falla (papel agotado, impresora ocupada), el sistema registra el error y puede reintentar automáticamente con control de idempotencia.

Autenticación Segura

Toda comunicación usa HTTPS y una api_key por sucursal. Sin credenciales compartidas entre locales.

Trazabilidad Completa

Cada impresión tiene un estado (QUEUED → PRINTING → SUCCESS / FAILED) visible desde el panel de ADEstock Cloud.

Requisitos

Agent Printer se instala en la PC del local, no en el servidor.

Windows 10 / 11

Arquitectura 64-bit. No requiere instalación de Python ni dependencias adicionales.

Impresora instalada

Visible en Windows (USB) o accesible por IP y puerto en la red local (LAN).

Conexión a Internet

Solo se necesita salida HTTPS (puerto 443) hacia tu dominio de ADEstock Cloud. Sin puertos entrantes.

Permisos de Administrador

Requeridos solo para la instalación inicial. El agente corre como tarea programada de Windows.

ADEstock Cloud activo

Necesitás ser cliente del plan Cloud de ADEstock con el módulo de cola de impresión habilitado.

API Key de sucursal

Se genera desde el panel de administración de ADEstock Cloud para cada sucursal/caja.

Instalación en 4 Pasos

Todo el proceso tarda menos de 5 minutos.

  1. 1

    Descargá el instalador

    Bajá AgentPrinter_Setup_vX.Y.Z.exe desde la sección de versiones más abajo y ejecutalo como administrador.

  2. 2

    Completá el formulario de configuración

    El instalador abre una pantalla donde ingresás:

    • Cloud URL — tu dirección de ADEstock Cloud
    • API Key — la clave del agente que generaste en el panel
    • Store ID — identificador de tu sucursal (ej. sucursal-centro)
    • POS ID — identificador de la caja (ej. caja-01)
    • Agent Name — nombre descriptivo (ej. PC-CAJA-01)
  3. 3

    El instalador configura todo automáticamente

    Copia los binarios en C:\Program Files\AgentPrinter\, guarda la configuración en %APPDATA%\AgentPrinter\ y crea una tarea programada de Windows para que el agente arranque solo con cada inicio del sistema.

  4. 4

    Verificá que el agente esté activo

    Desde ADEstock Cloud vas a ver el agente conectado con su estado de salud en tiempo real. Podés hacer una impresión de prueba directamente desde el panel para confirmar que todo funciona.
