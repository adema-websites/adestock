NUEVA VERSIÓN MAYOR Abril 2026

ADEstock v2.1.1 - Inteligencia Comercial, POS Visual y Control Total de Proveedores

Esta versión marca un antes y un después en la plataforma: compras asistidas por IA + OCR, mostrador más veloz con POS visual y favoritos, y un panel administrativo optimizado para operar incluso con bases de datos muy grandes.

Descarga Oficial

Incluye instalador para Windows y mejoras de rendimiento para entornos productivos exigentes.

Descargar Adestock_Installer_v2.1.1.exe

También disponible en GitHub Releases para trazabilidad del release y publicación técnica.

Novedades Principales

  • Inteligencia en compras: carga de listas de proveedores por Excel, CSV, PDF o imagen con OCR + IA para actualizar costos automáticamente.
  • Nuevo POS visual: explorador con imágenes, filtros rápidos y favoritos para acelerar ventas de mostrador.
  • Ecosistema de proveedores 360: estados de cuenta PDF, semáforo de deudas y pagos rápidos desde POS.
  • Modo Lite Admin: mejora extrema de performance en dashboard para bases de datos grandes.
  • Módulo Cocina: márgenes reales, historial de ventas y planificador inteligente de insumos por unidad de medida.

Módulos Actualizados

  • Entrenamiento OCR retroactivo: aprende desde compras históricas sin alterar contabilidad previa.
  • Reportes de cuentas corrientes en tiempo real para clientes y proveedores con exportación detallada.
  • Cobros POS con medios favoritos para simplificar pantalla y acelerar cierre de venta.
  • Compras con mayor flexibilidad para registrar flete como costo al proveedor o gasto separado.

Instalación / Actualización

Después de actualizar, ejecutá este comando obligatorio:

python manage.py migrate

Esta versión agrega tablas para trazabilidad de pagos a proveedores, optimización del Modo Lite y favoritos del POS.
